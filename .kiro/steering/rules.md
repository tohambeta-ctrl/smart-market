# Project Rules

These rules apply to all agent interactions in this workspace.

## General
- Always read the relevant file(s) before making any changes.
- Keep changes focused — only modify what is needed for the task.
- Do not add features, abstractions, or boilerplate beyond what is asked.

## Flutter / Dart
- Follow the existing code style and conventions already present in the project.
- Do not introduce new packages without asking first.
- Prefer named constructors and const widgets where applicable.

## Add your own rules below
- Always ensure that new files/screens are translated so that we can have translatable strings in both English and French
- Always ensure that you use the reusable widgets wherever they are applicable (eg buttons, cards etc). Create new ones where you see need for a reusable.
- Follow best coding practices always.
- Always respect the app theme and colors.
- Also respect the fonts as defined in theme folder.
